Calendar & reminders

“📅” adds one block to Google Calendar (repeating weekly for weekday and weekend plans). The .ics file has every weekday and weekend block as weekly events with reminders, plus this week’s late-morning days.

Block reminders: a notification at each block’s start time. Phones only deliver these reliably while the app is open or recently used, so keep your real alarms in the Clock app. The app can’t set phone alarms.

Dates: ISKCON Vaisnava calendar (GCal) via vaisnavacalendar.info, Dallas location, which shares Lubbock’s time zone. Break-fast windows use Lubbock sunrise and stay inside the Dallas window. Add or edit dates in Settings.
